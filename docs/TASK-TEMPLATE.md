# Szablon zadania

Każde zadanie musi mieć:

```markdown
### [ ] T-NNN · Tytuł
- **Wejście:** konkretne pliki i dane.
- **Wyjście:** konkretne ścieżki.
- **Weryfikacja:** dokładne polecenie i oczekiwany wynik.
- **Skończone, gdy:** mierzalne kryterium.
- **Poza zakresem:** czego nie robisz.
- **Zależy od:** numery zadań albo „nic”.
```

`[x]` wolno ustawić dopiero po rzeczywistej weryfikacji.
